## Conservation: what goes in comes out

At every node other than `s` and `t`, flow is neither created nor destroyed:

```
Σ_{u : (u,v) ∈ E} f_uv   =   Σ_{w : (v,w) ∈ E} f_vw        for every v ∈ V ∖ {s, t}
        inflow                      outflow
```

Read the subscripts as "every edge ending at `v`" on the left and "every edge starting at
`v`" on the right.

At node `d` in the running network, the edges into `d` come from `a` and `b`, and the edges
out go to `c`, `e` and `t`:

```
f_ad + f_bd = f_dc + f_de + f_dt
```

With the slide's example flow: `2 + 1 = 3` enter, and `1 + 0 + 2 = 3` leave.

Conservation is a **linear equality**, a sum of variables equal to another sum, so it fits
straight into an LP.

## The whole LP

```
maximise    F = Σ_{v : (s,v) ∈ E} f_sv
subject to  0 ≤ f_uv ≤ c_uv                       for every edge (u, v)
            inflow(v) = outflow(v)                for every v ≠ s, t
```

The **flow value** `F` is the total leaving the source. For the running network,

```
F = f_sa + f_sb + f_sc = f_dt + f_et
```

The second equality is not a separate constraint. It follows from conservation: whatever
leaves `s` and is never lost along the way must arrive at `t`.

## Counting the pieces

| piece | count | why |
| --- | --- | --- |
| variables | 11 | one per edge |
| capacity bounds | 11 | one pair `0 ≤ f ≤ c` per edge |
| conservation equations | 5 | one per intermediate node: `a`, `b`, `c`, `d`, `e` |

## Is the LP well behaved?

The LP has an optimum, for the reasons from the previous section:

- **feasible:** zero flow on every edge satisfies every constraint;
- **bounded:** finite capacities cap every variable, and so cap `F`.

One caveat from the slides: these examples have no edges *into* `s`. In general, define the
flow value as flow out of `s` *minus* flow into `s`.

A general LP solver could now finish the job. The rest of the section shows that the graph
structure allows something more direct.

> Maximum flow is an LP: one variable per edge, bounded by its capacity, with inflow equal
> to outflow at every intermediate node, and the total leaving the source as the objective.
> Zero flow is always feasible and capacities bound the value, so an optimum exists.
