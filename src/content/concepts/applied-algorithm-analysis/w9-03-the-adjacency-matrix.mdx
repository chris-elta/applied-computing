Label the vertices `1, 2, …, n`, and draw an `n × n` grid. To fill a cell, pick row `i` and
column `j`, look for the edge between `i` and `j`, and write 1 if it is there and 0 if not.
That grid is the **adjacency matrix**, `A`:

```
Aᵢⱼ = 1   if {i, j} is an edge
      0   otherwise
```

## A four-vertex example

The graph with edges `1–2`, `2–3`, `2–4`, `3–4`:

| | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| **1** | 0 | 1 | 0 | 0 |
| **2** | 1 | 0 | 1 | 1 |
| **3** | 0 | 1 | 0 | 1 |
| **4** | 0 | 1 | 1 | 0 |

Three things to read off it:

- **One edge, two 1s.** Edge `2–4` appears at row 2 column 4 and at row 4 column 2. That is
  what it means for the matrix to be **symmetric**, and every undirected graph's matrix is.
- **The diagonal is all zeroes**, because no vertex has an edge to itself.
- **Row sums are degrees.** Row 2 adds to 3, and vertex 2 touches three edges:
  `deg(2) = 3`. All the rows together add to `2m = 8`, since each edge was counted twice.

## Three variations

| graph | what goes in `Aᵢⱼ` |
| --- | --- |
| parallel edges | the number of edges between `i` and `j` |
| weighted | the weight `wᵢⱼ` — and a separate marker such as `+∞` for no edge |
| directed | 1 if an edge runs **from** `i` **to** `j` |

The directed case is the one to dwell on. A one-way edge from 3 to 4 puts a 1 at row 3
column 4 and leaves row 4 column 3 at 0. A directed graph's matrix is generally *not*
symmetric, and that asymmetry is exactly what a one-way street looks like in a grid.

In the weighted case, do not write 0 for "no edge". An edge of weight zero and no edge are
different facts.

## What it costs

The matrix has one cell per ordered pair of vertices: `n` rows of `n`. Delete every edge
from the four-vertex graph and there are still sixteen cells. So the space is **`Θ(n²)`**,
and `m` never appears in it.

For a dense graph that is fine — most cells hold a 1. For a sparse graph almost every cell
records that an edge does *not* exist. A road network with a million intersections would
need a trillion cells, nearly all zero.

> The adjacency matrix answers "is `i` joined to `j`?" in one lookup, and pays for it with
> `n²` cells whatever the graph looks like. That trade is good when the graph is dense, and
> wasteful when it is sparse.
