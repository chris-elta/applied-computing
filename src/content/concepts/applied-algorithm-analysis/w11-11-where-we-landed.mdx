## The week in one argument

| step | on the bakery | in general |
| --- | --- | --- |
| a plan shows what is possible | `(100, 300)` earns 1900 | any feasible `x` |
| weighted constraints show what is impossible | multipliers `(0, 5, 1)` give `Z ≤ 1900` | any feasible `y` gives `Z ≤ W` |
| the best multipliers are an LP | min `200y₁ + 300y₂ + 400y₃` | the dual |
| the two meet | `1900 = 1900` | `max Z = min W` |

## Why the dual looks the way it does

Each line of the dual is a requirement for the weighted sum to be a valid upper bound.

1. **Sign of each multiplier.** The weighted row must be a true `≤` statement, so a `≤` row
   needs `y ≥ 0`.
2. **Coefficient checks.** The weighted expression must be at least the objective. With
   `x ≥ 0`, each collected coefficient need only be at least the objective's.
3. **Minimise.** Among valid bounds, the smallest is the most informative.

## The rules

For a **maximisation** primal and its **minimisation** dual:

| primal row | dual variable | | primal variable | dual row |
| --- | --- | --- | --- | --- |
| `≤` | `yᵢ ≥ 0` | | `xⱼ ≥ 0` | `≥ cⱼ` |
| `=` | `yᵢ` free | | `xⱼ` free | `= cⱼ` |
| `≥` | `yᵢ ≤ 0` | | | |

Right-hand sides become objective coefficients, objective coefficients become right-hand
sides, and the coefficient matrix is transposed. In matrix form, for the all-`≤`,
all-non-negative case: max `cᵀx`, `Ax ≤ b`, `x ≥ 0` pairs with min `bᵀy`, `Aᵀy ≥ c`,
`y ≥ 0`.

## The theorem

> If a linear program has a finite optimum, then so does its dual, and the two optimal values
> are equal.

Max-flow min-cut is the special case where the primal is the flow LP and the bounds are cuts.

## The mistakes worth checking for

| mistake | correction |
| --- | --- |
| a negative multiplier on a `≤` row | it reverses the row, and the "bound" can be false |
| "the weighted sum must equal the objective" | at least the objective is enough when `x ≥ 0` |
| "a looser bound is a wrong bound" | 4300 is valid for the bakery. It is only less useful |
| dual with the primal's shape | `m` rows and `n` variables become `m` variables and `n` rows |
| equality row → equality dual row | equality row → free *multiplier*. Free variable → equality row |
| `y ≥ 0` for a `≥` row | `y ≤ 0` |
| "the optimal `x` and `y` are equal" | the *values* `Z` and `W` are equal. `x` and `y` differ even in length |

> Every linear maximisation has a partner minimisation whose feasible answers are upper
> bounds. Build it by giving each constraint a multiplier and each variable a coefficient
> check. When a finite optimum exists the two optimal values coincide, and a solution to each
> is a checkable proof that the other is optimal.
