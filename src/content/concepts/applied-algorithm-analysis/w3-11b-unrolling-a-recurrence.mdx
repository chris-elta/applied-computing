The master theorem only reads recurrences of one shape. When a recurrence does not fit it,
there is a method that needs no theorem at all: **expand it a few times by hand until a
pattern appears.** It is the recursion tree written as a single line of algebra.

## The method in four steps

1. **Replace the `O` with a constant.** `T(n) = T(n/2) + O(1)` becomes
   `T(n) ≤ T(n/2) + c`. You can add up numbers, but not `O`s.
2. **Substitute the rule into itself**, three or four times.
3. **Write the general term**, the bound after `k` substitutions.
4. **Choose `k`** so the remaining `T(…)` is the base case, `T(1)`, and simplify.

## A halving recurrence

Binary search costs `T(n) ≤ T(n/2) + c`. Apply the rule to `T(n/2)`, then to `T(n/4)`:

```
T(n) ≤ T(n/2) + c
     ≤ [T(n/4) + c] + c   = T(n/4) + 2c
     ≤ [T(n/8) + c] + 2c  = T(n/8) + 3c
     ...
     ≤ T(n/2ᵏ) + kc
```

The argument reaches 1 when `2ᵏ = n`, so take `k = log₂ n`:

```
T(n) ≤ T(1) + c·log₂ n = O(log n)
```

That matches the master theorem's balanced case for binary search, which is a useful check.
Whenever both methods apply, they agree.

## A subtracting recurrence

`T(n) ≤ T(n−1) + cn` is one of the shapes the master theorem cannot read: the problem shrinks
by **subtraction**, so there is no `b`. Unrolling does not care:

```
T(n) ≤ T(n−1) + cn
     ≤ T(n−2) + c(n−1) + cn
     ≤ T(n−3) + c(n−2) + c(n−1) + cn
     ...
     ≤ T(n−k) + c(n + (n−1) + ⋯ + (n−k+1))
```

Now the base case is `k = n − 1` steps away, not `log n`. Plugging that in leaves
`T(1) + c(2 + 3 + ⋯ + n)`, an arithmetic series of about `n²/2`. So `T(n) = O(n²)`. That is
the cost of selection sort, which removes one item per pass and scans the rest.

## What to watch

| feature of the recurrence | effect on the unrolled sum |
| --- | --- |
| argument **divides** by `b` | `k = log_b n` steps to the base case |
| argument **subtracts** 1 | `k ≈ n` steps to the base case |
| `a` copies of `T` on the right | a factor `aᵏ` builds up in front of `T(…)` |

The last row is the one that is easy to lose. With `a = 1`, as in both examples here, nothing
builds up. With `a > 1`, every substitution multiplies the leftover term by `a`, and you have
to carry `aᵏ` all the way to the choice of `k`. The `fib1` call count from week 1 is the warning
case: a recurrence that subtracts **and** branches.

> **Unrolling is the recursion tree, kept on one line.** Use it when the recurrence will not
> fit the master theorem, and use it to check the theorem when it does.
