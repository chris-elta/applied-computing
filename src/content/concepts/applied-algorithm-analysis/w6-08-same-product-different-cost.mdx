You have a row of matrices to multiply together: `A₁ × A₂ × ⋯ × Aₙ`. Matrix multiplication
is associative, so you may put the brackets wherever you like and the answer is the same
matrix. What is not the same is how much arithmetic it takes.

## What one multiplication costs

Multiplying a `p × q` matrix by a `q × r` matrix gives a `p × r` matrix. Each of its `p·r`
entries is a row of `q` numbers times a column of `q` numbers, which is `q` scalar
multiplications. So the cost is

```
p × q × r   scalar multiplications
```

rows of the left, times the shared dimension, times columns of the right.

## One product, two prices

`A` is `50 × 20`, `B` is `20 × 1`, `C` is `1 × 10`.

| Order | First product | Second product | Total |
| --- | --- | --- | --- |
| `(AB)C` | `50·20·1 = 1,000` | `50·1·10 = 500` | 1,500 |
| `A(BC)` | `20·1·10 = 200` | `50·20·10 = 10,000` | 10,200 |

Same result, almost 7 times the work.

`AB` is cheap because `B` has only 1 column. And the result `AB` is a thin `50 × 1` matrix,
so multiplying it by `C` is cheap too. The other order starts with the cheaper first step,
200 against 1,000, and then pays for it: `BC` is a `20 × 10` matrix, and multiplying `A` by
that drags all three large dimensions into one product.

So picking the cheapest multiplication available right now is not a safe rule. The first
step decides the *shape* of what you are left holding, and that shape sets the price of
everything after.

## The input is just a list of numbers

Neighbouring matrices must share a dimension, or they could not be multiplied. So write
matrix `Aᵢ` as `mᵢ₋₁ × mᵢ`. Then the whole problem is described by `n + 1` numbers:

```
m₀, m₁, …, mₙ
```

For the example, `m = 50, 20, 1, 10`. The entries of the matrices never matter. Only the
shapes do, and the order of the matrices is fixed. The single thing you get to choose is
where the brackets go.

**The problem.** Given `m₀, …, mₙ`, find the bracketing with the lowest total cost.

> When every order gives the same answer, the order is still a decision. Associativity
> tells you the choices are all correct; it does not tell you they all cost the same.
