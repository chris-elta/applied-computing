## Four things to keep

**1 · Greedy choices need a correctness argument.** With coins 1, 3 and 4, biggest-first
loses. For MSTs it is correct, because of the cut property: connect across a boundary as
cheaply as possible, without splitting a component already selected.

**2 · A spanning tree is connected and has `n − 1` edges.** With positive costs, every
cheapest connected network is a tree. The MST problem itself also allows zero and negative
weights.

**3 · Both algorithms run in `O((m + n) log n)`.** Indexed-heap Prim pays for heap
operations. Kruskal pays for sorting and for union-find checks.

**4 · Distinct weights guarantee a unique MST.** With tied weights the MST may or may not be
unique. Different valid runs can return different MSTs, all with the same total weight.

## The algorithms in one table

| | Prim | Kruskal |
| --- | --- | --- |
| basic version | rescan all edges each round: `O(mn)` | DFS per cycle check: `O(mn)` |
| fast version | indexed heap: `O((n + m) log n)` | union-find with union by rank: `O((n + m) log n)` |
| which cut it uses | `X` against the rest | one component against the rest |

## Think first

Try each before reading the answer under it.

**If heap-based Prim stops when its smallest key is ∞, what does it return on a
disconnected graph?**
An MST of the start vertex's component only. Vertices that cannot be reached keep key ∞.
For a spanning forest, restart Prim from an unreached vertex, or use Kruskal, which produces a
forest anyway.

**Does adding 1 to every edge weight change the MST?**
No. Every spanning tree has `n − 1` edges, so every tree's total rises by exactly `n − 1`, and
the cheapest tree stays the cheapest. This holds even when some weights are negative.

**Does squaring every weight change it?**
With non-negative weights, no: squaring keeps their order, and both algorithms only compare
weights. With negative weights it can. In a triangle with weights −3, −2 and 1 the MST takes
−3 and −2. After squaring the weights are 9, 4 and 1, and the MST takes 1 and 4.

The last two have the same underlying point: **an MST depends only on the order of the
weights.** Any change that keeps the order keeps the MST.
