The table method costs `O(n²)` because for every element it looks back at all earlier
elements. A different idea brings that down to `O(n log n)`, and it rests on one observation
about which subsequences are worth remembering.

## One new word

The **tail** of a subsequence is its last number. The tail of `[2, 5, 7]` is 7.

## Which would you rather keep?

Take `nums = [5, 12, 8, 10]`. After reading 5, 12 and 8 there are two increasing
subsequences of length 2: `[5, 12]` and `[5, 8]`. Then 10 arrives.

| Subsequence | Tail | Can 10 follow? |
| --- | --- | --- |
| `[5, 8]` | 8 | yes — `[5, 8, 10]`, length 3 |
| `[5, 12]` | 12 | no — 10 is smaller than 12 |

It is not an accident that the one with the smaller tail did better. Any number that can be
added after 12 must be bigger than 12, so it is also bigger than 8, so it can be added after
8 too. `[5, 12]` can never do anything `[5, 8]` cannot. It can be forgotten.

That argument used nothing about these particular numbers. Among all increasing subsequences
of the same length, the one with the **smallest tail** can be extended by everything the
others can. So for each length, one number is enough.

## The array `sub`

Keep one array. Group the increasing subsequences seen so far by length, and for each group
store only the smallest tail:

| Entry | Holds the smallest tail of an increasing subsequence of length |
| --- | --- |
| `sub[0]` | 1 |
| `sub[1]` | 2 |
| `sub[k]` | `k + 1` |

Read that last row twice. Positions count from 0 and lengths from 1, so position `k` means
length `k + 1`. In the example, after 5, 12, 8 the array is `sub = [5, 8]`: the smallest
tail of length 1 is 5 and of length 2 is 8.

Since there is an entry for every length that has been achieved, **the length of `sub` is
the longest length found so far**. When the whole input has been read, that is the LIS.

Notice what has been given up. `sub` does not remember the subsequences, only their last
numbers — and only one last number per length. That is why it is small, and it will matter
two concepts from now.

> Among candidates of equal length, keep the one that leaves the most room to grow. For
> increasing subsequences that means the smallest last number.
