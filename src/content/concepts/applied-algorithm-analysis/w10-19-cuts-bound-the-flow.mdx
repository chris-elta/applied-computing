Before finding a good flow, find a limit on how good any flow can be. This is the
upper-bound half of the plan-and-bound argument.

## A cut around the sink

In the seven-node network, every unit that reaches `t` arrives on `d → t` or `e → t`. Those
pipes carry 2 and 5:

```
F = f_dt + f_et ≤ 2 + 5 = 7
```

No flow can exceed 7, whatever happens elsewhere in the network.

## Cuts in general

An **s–t cut** splits the vertices into two groups, `S` containing `s` and `T` containing
`t`. The example used `S = {s, a, b, c, d, e}` and `T = {t}`.

The **cut capacity** `C(S, T)` adds the capacities of the original edges directed **from S to
T**. Here those are `d → t` and `e → t`, so `C(S, T) = 7`.

**Every feasible flow is at most every cut's capacity.** Each unit must cross from `S` into `T`
at some point, and the edges it can cross on hold `C(S, T)` in total. So

```
any feasible flow  ≤  min-cut value
```

where the min-cut value is the smallest capacity over all cuts.

## Only forward edges count

Edges from `T` back to `S` are not added to the capacity. Take the four-node network with
`S = {s, B}` and `T = {A, t}`:

| edge | direction | counted? |
| --- | --- | --- |
| `s → A` (3) | S to T | yes |
| `B → t` (2) | S to T | yes |
| `A → B` (4) | T to S | no |

`C(S, T) = 3 + 2 = 5`.

## Why the bound holds: the algebra

Sum conservation over every vertex in `S`. Edges inside `S` cancel, since each is outflow for
one endpoint and inflow for the other. Only `s` has net outflow, which is `F`. What remains
is the identity

```
F = (flow on S→T edges) − (flow on T→S edges)
```

In the four-node example with the maximum flow, 3 + 2 units cross into `T` and 1 returns on
`A → B`: `5 − 1 = 4 = F`.

Then two facts finish it. Returning flow is at least 0, and forward flow is at most capacity:

```
F ≤ flow on S→T edges ≤ C(S, T)
```

The bound is tight exactly when **every S→T edge is full and every T→S edge is empty**. The
max-flow min-cut proof shows that Ford–Fulkerson ends in exactly that state.

> Every s–t cut bounds every flow, because each unit must cross from `S` to `T`. The bound
> is the total capacity of the edges leaving `S`. Edges back into `S` are not counted. A
> flow equal to some cut's capacity is therefore maximum.
