You start a 25-episode season at midnight, three hours an episode. What time do you finish?

`25 × 3 = 75` hours — and you did not count 75 hours forward. You divided by 24 and kept the
remainder: **3 a.m.**, three days later. That instinct is the entire subject.

Days of the week work the same way mod 7, and so do wrapping array indices, hash tables, and
every cryptosystem in the second half of this course.

## The definition

`x mod N` is the remainder when `x` is divided by `N`. Formally, there is a quotient `q` and
a remainder `r` with

```
x = qN + r,   with 0 ≤ r < N
```

and `N` is the **modulus** — the size of the clock face.

That `0 ≤ r < N` is not housekeeping. It is what makes `−7 mod 3 = 2` rather than `−1`, and
it is the single most common source of off-by-a-modulus bugs.

## Reading the notation

One rule that saves a lot of grief: **`mod` binds loosest** — looser than `×` and `+`.

```
a · b mod N   means   (a · b) mod N        not   a · (b mod N)
```

These are genuinely different integers: `3 · (13 mod 5) = 9`, while `(3 · 13) mod 5 = 4`.
They *are* congruent mod 5, which is why the distinction feels slippery — but only one of
them is a remainder. Every formula in this week's material uses the loose-binding reading.

## Two ways to picture it

**Restriction.** The numbers are confined to the set `{0, 1, …, N−1}`, wrapping like an hour
hand once they reach the end.

**Folding.** All the integers are kept, but grouped into `N` piles by their remainder. Mod 5,
the pile labelled 2 holds `…, −8, −3, 2, 7, 12, 17, …` — every number differing from 2 by a
multiple of 5. Each pile is an **equivalence class**.

The second picture is the more useful one, and it is what makes the next page's substitution
rule obvious rather than surprising.
