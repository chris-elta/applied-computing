The four-town problem in general: you have locations and a list of possible links, each with
a positive cost. The network must be **connected**, with a path between every pair of
locations. Subject to that, build it as cheaply as possible. The previous two concepts showed
that the answer is a tree on all the vertices.

## Spanning trees

A **spanning tree** of a weighted undirected graph is a set of its edges that

- forms **no cycles**, and
- **connects every pair** of vertices with a path.

A graph usually has many. Four vertices with every pair joined have 16. The four-town graph
has 8, because it is missing the edge `(b, c)`.

In general, `n` vertices with every pair joined have `nⁿ⁻²` spanning trees. For 10 vertices
that is `10⁸`, a hundred million, and for 20 it is about `2.6 × 10²³`. Listing them all and
picking the cheapest is not an option.

## The problem, formally

| | |
| --- | --- |
| **Input** | a connected, undirected graph `G = (V, E)`; edge weights may be positive, zero or negative |
| **Output** | a tree `T = (V, E′)`, with `E′ ⊆ E`, that minimises `weight(T) = ∑_{e ∈ E′} wₑ` |

Two details:

- **`T` uses all of `V`.** The tree has to reach every vertex, which is what makes it
  spanning.
- **Weights can be zero or negative.** The cycle-removal argument needed positive weights,
  but here the output is required to be a tree, so cycles are ruled out by definition. The
  algorithms in this lecture work with any weights.

## There can be more than one

The six-vertex example on slide 14 has edges `A–C` 1, `C–D` 2, `A–D` 3, `A–B` 4, `B–C` 4,
`B–D` 4, `C–F` 4, `E–F` 5 and `D–F` 6. One MST is

`A–C (1) + C–D (2) + B–D (4) + C–F (4) + E–F (5) = 16`.

`B` hangs off the tree by `B–D`. It could hang off by `A–B` or `B–C` instead, both also
weight 4, and the total would still be 16. So this graph has at least three MSTs.

| Weights | MST |
| --- | --- |
| all distinct | exactly one |
| some tied | maybe one, maybe several, all with the same total |

So "the MST" is only correct wording when the MST is unique. Two correct algorithms, or two
runs that break ties differently, can return different trees with the same weight.

> Many spanning trees exist, and enumerating them is hopeless. The minimum total weight is
> one number, but with tied weights several trees can achieve it.
