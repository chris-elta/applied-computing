Ford–Fulkerson stops when no augmenting path remains. Why should that mean the flow is
**maximum**, and not only that the algorithm is stuck? The proof builds a cut from the final
residual graph and shows the flow equals its capacity.

## Step 1 · Every cut limits the flow

From the earlier concept on cuts: for any cut, `any feasible flow ≤ C(S, T)`, so

```
F ≤ min-cut value
```

## Step 2 · Read a cut off the final residual graph

When the algorithm stops, define

- `S` = every vertex reachable from `s` in the residual graph;
- `T` = everything else. `t` is in `T`, since otherwise there would be an augmenting path.

The key fact: **no positive residual edge leaves `S`**. If one did, its far end would be
reachable, so it would be in `S`. Apply that to the two kinds of original edge crossing the
cut.

**2a · S → T edges are full.** Suppose an original edge `u → v` from `S` to `T` had
`f < c`, say flow 3 of capacity 5. Its unused capacity creates a forward residual edge
`u → v` of capacity 2. Then `v` is reachable, although it is in `T`, a contradiction. So
`f = c`.

**2b · T → S edges carry zero flow.** Suppose an original edge `v → u` from `T` to `S`
carried flow 2. That flow could be cancelled, which creates a backward residual edge
`u → v` of capacity 2, again from `S` into `T`. Same contradiction. So `f = 0`.

Now use the identity `F = (flow S→T) − (flow T→S)`:

```
F = C(S, T) − 0 = C(S, T)
```

In the four-node trace this cut was `S = {s, A, B}`, with `4 = 2 + 2`.

## Step 3 · Combine

```
F ≤ min-cut value ≤ C(S, T) = F
```

The first `≤` is step 1. The second holds because the minimum is at most any particular
cut. The `=` is step 2. A chain that starts and ends at `F` forces every link to be equal.
So the flow equals the min-cut value, no flow can exceed it, and **the flow is maximum**.

## The theorem

> **Max-flow min-cut.** The maximum s–t flow value equals the minimum s–t cut capacity.

The proof gives more than the statement:

- **Ford–Fulkerson is correct.** Stopping means maximum.
- **It certifies its own answer.** The reachable set is a minimum cut, a proof anyone can
  check by adding capacities.
- **This is duality in miniature.** One maximisation, flow, and one minimisation, cut,
  bound each other and meet at the optimum. The lesson on LP duality generalises this.

> When no augmenting path remains, the vertices reachable from `s` form a cut whose outgoing
> edges are full and whose incoming edges are empty, so the flow equals that cut's capacity.
> Since every flow is at most every cut, the flow is maximum and the cut is minimum.
