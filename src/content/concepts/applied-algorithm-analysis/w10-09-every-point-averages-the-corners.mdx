The equal-profit picture shows a vertex is optimal. This proof shows that *no* feasible
point can beat the best vertex, and that works in any number of dimensions, where pictures
stop.

## A worked example

Take the feasible point `P = (100, 200)`, which is inside the bakery region and not a
corner. The relevant vertices are `A = (0, 0)`, `B = (0, 300)` and `C = (200, 200)`.

**Step 1: go sideways to the boundary.** A horizontal line through `P` hits the boundary at
`L = (0, 200)` on the left and `C = (200, 200)` on the right. `P` is halfway between them:

```
P = ½L + ½C
```

`C` is already a vertex. `L` is not. It lies on the edge from `A` to `B`.

**Step 2: replace `L` by its edge's endpoints.** `L` is two-thirds of the way from `A` up to
`B`, since 200 is ⅔ of 300:

```
L = ⅓A + ⅔B
```

Substitute it in:

```
P = ½(⅓A + ⅔B) + ½C = ⅙A + ⅓B + ½C
```

The weights ⅙, ⅓ and ½ are non-negative and sum to 1. Check the coordinates:
`⅙(0, 0) + ⅓(0, 300) + ½(200, 200) = (100, 200)`.

**Step 3: compare profits.** Because `Z = x₁ + 6x₂` is linear, the same weights apply to the
profits:

| vertex | profit |
| --- | --- |
| A | $0 |
| B | $1800 |
| C | $1400 |

```
Z(P) = ⅙(0) + ⅓(1800) + ½(1400) = 0 + 600 + 700 = 1300 ≤ 1800
```

Directly, `100 + 6(200) = 1300`, which agrees. `P` cannot beat `B`, because a weighted
average cannot exceed its largest input.

## The general argument

In a nonempty, bounded, convex polygon, the same two moves work from any point: draw a line
to the boundary, then write each endpoint using its edge's vertices. So every feasible `x`
is a convex combination of the vertices `v₁, …, vₖ`:

```
x = Σ λᵢvᵢ,     λᵢ ≥ 0,     Σ λᵢ = 1
```

Linearity then gives

```
Z(x) = Σ λᵢ Z(vᵢ) ≤ max Z(vᵢ)
```

No feasible point beats the best vertex, so at least one vertex is optimal. Nothing stops
two vertices from tying, and then the whole edge between them is optimal too.

> Every point of a bounded convex region is a weighted average of its vertices. A linear
> objective takes the same average of the vertices' values, and an average cannot exceed
> its largest input, so the best vertex is at least as good as any feasible point.
