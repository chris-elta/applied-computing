> **Lemma.** On average, a fair coin needs to be tossed **two** times before a head is seen.

A pivot is good with probability ½, so "how many picks until a good pivot?" is exactly "how
many tosses until a head?"

## Proof

Let `X` be the number of tosses up to and including the first head, and `E[X]` its **expected
value** — the long-run average of `X` over many repetitions.

The tool is the **law of total expectation**: split on the result of the first toss.

```
E[X] = P(head)·E[X ∣ 1st is head] + P(tail)·E[X ∣ 1st is tail]
```

**Case 1 — the first toss is a head (probability ½).** The head has arrived on toss 1, so
`X = 1`, and therefore `E[X ∣ 1st is head] = 1`.

**Case 2 — the first toss is a tail (probability ½).** One toss is spent with no head, so the
tossing goes on. Write `X′` for the tosses counted afresh from toss 2 until a head appears:
`X = 1 + X′`. The tosses are independent — the coin has no memory — so counting from toss 2 is
the *same experiment* as counting from toss 1. So `X′` has the same distribution as `X`,
giving `E[X′] = E[X]` and `E[X ∣ 1st is tail] = 1 + E[X′] = 1 + E[X]`.

## Substitute and solve

Write `E` for `E[X]`. Putting the two cases into the law of total expectation:

```
E = ½·1 + ½(1 + E) = 1 + ½E
```

Subtract `½E` from both sides, so that `½E = 1`, and

```
E[X] = 2   ∎
```

**Why that subtraction is allowed.** It is arithmetic on a number, so `E[X]` has to be finite
before it may be done — and `E[X] = ∞` satisfies the same equation too. It is finite: `X > k`
only if the first `k` tosses are all tails, so `P(X > k) = 2⁻ᵏ`, which dies away
geometrically fast, ruling out an infinite average.
