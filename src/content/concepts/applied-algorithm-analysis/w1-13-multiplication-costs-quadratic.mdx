Addition came out at `Θ(n)`. Multiplication is where big numbers start to hurt.

## The rule as an instruction

> Halve `y`, double the product, and add `x` back if `y` was odd.

```
function multiply(x, y)
  if y = 0: return 0
  z = multiply(x, ⌊y/2⌋)
  if y is even: return 2z
  else: return x + 2z
```

`⌊y/2⌋` is `y` halved and **rounded down** — `⌊7/2⌋ = 3`. Why it works: if `y` is even,
`x·y = 2·(x·(y/2))`; if odd, peel off one `x` and the rest is even.

## Schoolbook multiplication, in binary

```
    1 1 0 1     (13)
  × 1 0 1 1     (11)
  ───────────
    1 1 0 1     13 × 1
  1 1 0 1 ·     13 × 1, shifted once
0 0 0 0 · ·     13 × 0, shifted twice
1 1 0 1 · · ·   13 × 1, shifted three times
───────────────
1 0 0 0 1 1 1 1 (143)
```

Each row is a **partial product**. In decimal that needs a real multiplication per row; in
binary the digit is 0 or 1, so every row is either **nothing** or **a copy of `x`**.
Shifting is free — append a zero.

**Cost:** the multiplications are free; the additions are not. There are `n` partial
products, each up to `2n` bits, added one after another.

> `n` rows × `O(n)` per row = **`O(n²)`**

That "how many × how much each" shape is the standard way to price an algorithm, and you use
it three more times this week.

## Al-Khwarizmi's method: same price, different ritual

Double the left column, halve the right, and keep the left values whose right partner is
**odd**.

| `x` — double | `y` — halve | odd? | keep |
| --- | --- | --- | --- |
| 11 | 13 | yes | 11 |
| 22 | 6 | no | — |
| 44 | 3 | yes | 44 |
| 88 | 1 | yes | 88 |
| — | 0 | stop | **143** |

Not sorcery: the rows kept are exactly the 1-bits of `13 = 1101₂`. Halving repeatedly *is*
reading off binary digits; doubling *is* shifting. This is binary shift-and-add, written a
thousand years before binary.

`n` rounds × `O(n)` per addition = **`O(n²)`** — identical to schoolbook.

> Two methods that look nothing alike cost the same, because they are the same algorithm in
> different clothing. Beating `O(n²)` needs a different **idea** — divide and conquer, as
> Karatsuba's algorithm, in a later week.
