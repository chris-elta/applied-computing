The slides pose this one as an exercise. Try it before reading on: write the objective, the
constraints and the variable signs.

```
max   Z = 5x₁ − x₂ + 2x₃
s.t.   x₁ +  x₂ + 4x₃  = 8
      3x₁ − 2x₂        ≥ 4
      x₁, x₂ ≥ 0,   x₃ free
```

## Count first

Two primal constraints give two dual variables. Three primal variables give three dual
constraints. The dual will not be the same shape as the primal, so there is no way to get it
by copying rows.

## Objective

Right-hand sides 8 and 4: `min W = 8y₁ + 4y₂`.

## One dual row per primal column

`x₃` does not appear in row 2, so its entry there is 0.

| primal variable | column (row 1, row 2) | objective coefficient | sign | dual row |
| --- | --- | --- | --- | --- |
| `x₁` | 1, 3 | 5 | `≥ 0` | `y₁ + 3y₂ ≥ 5` |
| `x₂` | 1, −2 | −1 | `≥ 0` | `y₁ − 2y₂ ≥ −1` |
| `x₃` | 4, 0 | 2 | free | `4y₁ = 2` |

Two details in this table are where marks are lost:

- The `−1` and the `−2` are copied with their signs. A negative right-hand side on a dual
  row is normal.
- The 0 means `y₂` is absent from the third row. It is still a row of the dual.

## One sign per primal row

| primal row | type | dual variable |
| --- | --- | --- |
| `x₁ + x₂ + 4x₃ = 8` | `=` | `y₁` free |
| `3x₁ − 2x₂ ≥ 4` | `≥` | `y₂ ≤ 0` |

The `≥` row is new. Its multiplier must be zero or negative, because multiplying a `≥`
statement by a negative number reverses it into the `≤` statement the sum needs.

## The dual

```
min   W = 8y₁ + 4y₂
s.t.  y₁ + 3y₂  ≥ 5
      y₁ − 2y₂  ≥ −1
      4y₁       = 2
      y₁ free,   y₂ ≤ 0
```

Summary, as the slide gives it: equality row → `y₁` free; `≥` row → `y₂ ≤ 0`;
`x₁, x₂ ≥ 0` → two `≥` dual rows; `x₃` free → `4y₁ = 2`.

## Marking your own attempt

| check | common wrong answer |
| --- | --- |
| three dual rows | two, from reading across the primal's rows |
| `y₂ ≤ 0` | `y₂ ≥ 0`, out of habit from the `≤` case |
| `y₁` free | `y₁ ≥ 0`, forgetting row 1 is an equation |
| third row is `=` | `4y₁ ≥ 2`, forgetting `x₃` is free |
| `≥ −1` in row 2 | `≥ 1`, dropping the sign |

The exercise asks only for the dual's form. The slides do not go on to solve either program,
and neither does this page.

> A `≥` row in a max primal gets a multiplier that is `≤ 0`. Count rows and variables before
> writing anything: the dual has as many rows as the primal has variables, including
> variables that are absent from some constraints.
