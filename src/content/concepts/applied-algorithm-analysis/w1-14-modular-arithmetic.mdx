You start a 25-episode season at midnight, 3 hours an episode. What time do you finish?

`25 × 3 = 75` hours — and you did not count 75 hours forward. You divided by 24 and kept the
remainder: **3 a.m.** That instinct is the entire subject.

## The definition

`x mod N` is the remainder when `x` is divided by `N`. Formally, there is a quotient `q` and
remainder `r` with

```
x = qN + r,   with 0 ≤ r < N
```

`N` is the **modulus** — the size of the clock face.

That `0 ≤ r < N` looks like housekeeping. It is the single most common source of bugs in
modular code. **Test it:** what is `−7 mod 3`?

Tempting: `−1`, from `−7 = (−2)(3) + (−1)`. But `−1` violates `0 ≤ r`. Push further:
`−7 = (−3)(3) + 2`. So `−7 mod 3 = 2`. Remainders are never negative. (Several programming
languages disagree; mathematics does not.)

## Two pictures

**Restriction** — numbers confined to `0 … N−1`, wrapping like an hour hand.

**Folding** — all integers kept, grouped into `N` piles by remainder. Mod 5, the pile
labelled 2 holds `…, −8, −3, 2, 7, 12, …`. Each pile is an **equivalence class**.

## Congruence: the three-line equals

```
x ≡ y (mod N)
```

`≡` is deliberately not `=`: 17 and 5 are not equal, but mod 12 they are indistinguishable.
Two equivalent readings — same remainder, or difference is a multiple of `N`.

| claim | difference a multiple of 12? | same remainder? |
| --- | --- | --- |
| `17 ≡ 5 (mod 12)` | `12` ✓ | both 5 ✓ |
| `−3 ≡ 9 (mod 12)` | `−12` ✓ | both 9 ✓ |
| `14 ≡ 5 (mod 12)` | `9` ✗ | 2 vs 5 ✗ |

The middle row trips people, for the reason above: `−3 mod 12` is `9`.

## The substitution rule

> If `x ≡ x′` and `y ≡ y′ (mod N)`, then `x + y ≡ x′ + y′` and `xy ≡ x′y′`.

In plain terms: **swap any number for another in its pile, at any point, without changing
the answer.** Ordinary algebra still works. Watch what that buys:

```
2³⁴⁵ ≡ (2⁵)⁶⁹ ≡ 32⁶⁹ ≡ 1⁶⁹ ≡ 1 (mod 31)
```

`2³⁴⁵` is a 104-digit number we never wrote down. We spotted `32 ≡ 1`, swapped, and it
collapsed. The next page turns that move into a technique.
