Four towns, `a`, `b`, `c` and `d`. Five cables could be laid, each with a cost:

| Cable | Cost |
| --- | --- |
| `(a, b)` | 1 |
| `(b, d)` | 2 |
| `(a, d)` | 3 |
| `(a, c)` | 4 |
| `(c, d)` | 5 |

Every town must be able to reach every other, possibly through other towns. What is the
cheapest set of cables that does it?

The answer is `(a, b)`, `(b, d)` and `(a, c)`, which costs `1 + 2 + 4 = 7`. Before seeing how
to find that, look at its shape: three cables for four towns, and no loops.

## The vocabulary

The lecture's words for the picture:

| Word | Meaning |
| --- | --- |
| vertex, edge | a vertex is a dot; an edge joins two of them |
| weight | a number on an edge, such as a cable's cost |
| undirected | an edge works both ways: `(a, b)` is the same as `(b, a)` |
| path | a route along edges from one vertex to another |
| connected | every pair of vertices has a path between them |
| cycle | a closed route with no repeated vertex except the start, which is also the end |

The goal, in these words: choose edges so the graph is **connected**, with the smallest
possible total **weight**.

## Why the answer never has a cycle

Suppose the cheapest connected network did contain a cycle, through vertices `u` and `v`
among others.

1. Remove the edge `(u, v)`. Any trip that used it can go the other way round the cycle
   instead, so every vertex can still reach every other.
2. The network is still connected, and it costs less, because every edge cost is positive.
3. That contradicts the assumption that it was the cheapest.

So the cheapest connected network has no cycles. A graph that is connected and has no cycles
is called a **tree**, and the next two concepts are about trees.

## The assumption that matters

Step 2 needs every cost to be **positive**. If the removed edge cost 0, removing it would not
save anything. If it cost −3, the network would get *more* expensive. With zero or negative
costs, the cheapest connected set of edges can contain a cycle.

The minimum spanning tree problem, defined two concepts on, asks for the cheapest **tree**,
and that question still makes sense with any weights. It is the step from "cheapest network"
to "it must be a tree" that relies on positive costs.

> If an edge lies on a cycle, removing it keeps everything connected. With positive costs,
> that makes the cheapest network a tree.
