An LP is *linear* in a precise sense, and checking it takes one rule.

> **Every term must be a fixed number times a single decision variable.**

Add any number of such terms and you have a linear function.

## Testing the rule

| expression | linear? | why |
| --- | --- | --- |
| `x₁ + 6x₂` | yes | 1 and 6 are fixed numbers |
| `x₁/2 + x₂ ≤ 200` | yes | dividing by 2 is a coefficient of ½ |
| `x₁x₂ ≤ 200` | no | two decision variables multiplied |
| `x₁² + x₂ ≤ 200` | no | a variable squared is a variable times itself |
| `x₁/x₂` | no | the denominator is a decision variable |

The danger sign is two variables in one term, whether multiplied, divided or a variable raised
to a power.

## The formal definition

A function `f : ℝⁿ → ℝ` is **linear** if, for all inputs `u`, `v` and all numbers `α`, `β`,

```
f(αu + βv) = α f(u) + β f(v)
```

Scaling or adding the inputs scales or adds the outputs the same way. That is the same as
saying `f` has the form

```
f(x) = aᵀx = Σᵢ aᵢxᵢ = a₁x₁ + ⋯ + aₙxₙ
```

with the coefficients `aᵢ` fixed in advance. That is the table's rule in algebra.

## Constants are allowed, in a sense

Add a fixed constant and you get an **affine** function, `g(x) = aᵀx + b`. Strictly it is
not linear unless `b = 0`. Every linear function has `f(0) = 0`, and `g(0) = b`.

LPs accept affine terms anyway, because constants are easy to remove:

| where the constant is | what to do |
| --- | --- |
| in a constraint, `x₁ + x₂ + 50 ≤ 400` | move it to the right: `x₁ + x₂ ≤ 350` |
| in the objective, `max x₁ + 6x₂ + 100` | ignore it. It adds 100 to every plan, so the best plan does not change. |

The constant in the objective changes the optimal *value* by 100, but not which plan
achieves it.

## Why linearity matters

The whole of the next section depends on this rule. Linearity makes the feasible region
convex, and it is the step in the proof that a corner is always optimal. A model with
`x₁x₂` in it loses both properties. Its region can curve, and its best point can be
anywhere.

> A linear program allows only a fixed coefficient times a single variable in each term. A
> product of variables or a variable raised to a power breaks that rule, and with it the
> geometry that makes LPs solvable.
