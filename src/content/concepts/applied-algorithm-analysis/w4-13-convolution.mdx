Take two vectors of length `n`, `a = (a_0, …, a_{n−1})` and `b = (b_0, …, b_{n−1})`. Their
**convolution** `c = a * b` is a new vector of length `2n − 1`, one coordinate at a time:

```
c_k = ∑_{i=0}^{k} a_i · b_{k−i},   0 ≤ k ≤ 2n − 2
```

Terms with indices outside `[0, n−1]` are taken to be zero. So `c_k` is the total contribution
of every pair `(a_i, b_j)` with `i + j = k`.

## Every product, sorted by `i + j`

Lay out all `n²` products `a_i · b_j` in a grid, then group them by anti-diagonal: every cell
on the same anti-diagonal shares the same value of `i + j`, and that shared value is exactly
which output `c_k` the cell contributes to. For `n = 4` that's `n² = 16` products collapsing
into `2n − 1 = 7` outputs.

Computing the convolution straight from this grid costs `n²` multiplications. The rest of this
module is about not paying that.
