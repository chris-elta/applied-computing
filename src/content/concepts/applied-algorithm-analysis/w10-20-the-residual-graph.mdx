## When adding alone gets stuck

Take a four-node network and a flow of 3 (labels are flow / capacity):

| edge | flow / capacity |
| --- | --- |
| `s → A` | 3 / 3 |
| `s → B` | 0 / 3 |
| `A → B` | 2 / 4 |
| `A → t` | 1 / 2 |
| `B → t` | 2 / 2 |

Look for an `s`–`t` path where every edge has room left. `s → A` is full. `s → B` has room,
but the only way on from `B` is `B → t`, and that is full. Adding flow is blocked.

Yet a flow of 4 exists. **Move one unit off `A → B`** and reroute:

- `s → B` carries 1 more, 0 → 1,
- `A → B` carries 1 less, 2 → 1,
- `A → t` carries 1 more, 1 → 2.

Now `A`'s unit takes `A → t` directly, which frees space on `B → t` for the new unit from
`s → B`. To improve a flow you must sometimes **cancel earlier choices**, so you need to
record what can be cancelled as well as what can be added.

## Residual edges for one pipe

An original edge `u → v` with capacity `c = 6` and current flow `f = 4` allows two kinds of
change:

| possible change | residual edge | residual capacity |
| --- | --- | --- |
| add up to 2 more | forward `u → v` | `c − f = 6 − 4 = 2` |
| cancel up to 4 | backward `v → u` | `f = 4` |

Using `v → u` does not send anything from `v` to `u`. It **cancels** flow on `u → v`.
Cancelling 1 unit takes the flow from 4 to 3.

The **residual graph** keeps the same vertices and includes every residual edge with
**positive** capacity. A full edge loses its forward edge. An empty edge has no backward one.

## Why backward edges are essential

| residual graph | outcome on the example |
| --- | --- |
| forward edges only | stuck at flow 3 |
| forward and backward | path `s → B → A → t` gives flow 4, the maximum |

The path goes forward on `s → B`, *backward* along `A → B` from `B` to `A`, then forward on
`A → t`. Think of revising a delivery plan: undo part of one route so more can be sent along
another.

Without backward edges, the first few paths chosen can block the maximum. With them, no early
choice is permanent.

> The residual graph records every allowed change. Each original edge gives a forward edge
> for its unused capacity `c − f` and a backward edge for its cancellable flow `f`. Backward
> edges let the algorithm undo earlier choices, and without them it can get stuck below the
> maximum.
