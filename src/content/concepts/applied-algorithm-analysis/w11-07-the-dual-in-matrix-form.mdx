The bakery's dual was built by hand: collect what multiplies `x₁`, collect what multiplies
`x₂`, compare each to the objective. That procedure is the same for any LP of the same kind,
and matrix notation writes it once for all of them.

## Packing the bakery into `A`, `b`, `c`

Write the constraint coefficients as a grid, one row per constraint and one column per
variable. A variable missing from a constraint gets a 0.

```
          x₁  x₂
     A = [ 1   0 ]      b = (200, 300, 400)      c = (1, 6)
         [ 0   1 ]
         [ 1   1 ]
```

Then `Ax ≤ b` says all three constraints at once, and `cᵀx` is the objective `x₁ + 6x₂`.

## The general pair

For `≤` constraints and non-negative primal variables:

| | primal | dual |
| --- | --- | --- |
| objective | max `cᵀx` | min `bᵀy` |
| constraints | `Ax ≤ b` | `Aᵀy ≥ c` |
| variables | `x ≥ 0` | `y ≥ 0` |

Here `A` has `m` rows and `n` columns, `b` has `m` entries and `c` has `n`. So `x` has `n`
variables and `y` has `m`.

## Why the transpose appears

To find what multiplies `x₁` in the weighted sum, you read *down* the `x₁` column of `A`,
taking each entry times its row's multiplier: `1·y₁ + 0·y₂ + 1·y₃ = y₁ + y₃`. A column of `A`
is a row of `Aᵀ`, so the collected coefficients are the entries of `Aᵀy`:

```
          y₁  y₂  y₃
    Aᵀ = [ 1   0   1 ]       Aᵀy = (y₁ + y₃,  y₂ + y₃)  ≥  (1, 6) = c
         [ 0   1   1 ]
```

Those are the bakery's two dual constraints. And `bᵀy = 200y₁ + 300y₂ + 400y₃` is its
objective. The slide notes that `Aᵀy ≥ c` is the column-vector way of writing `yᵀA ≥ cᵀ`.
Both say the same `n` inequalities.

## What to read off

| in the primal | in the dual |
| --- | --- |
| `m` constraints | `m` variables |
| `n` variables | `n` constraints |
| limits `b` | objective coefficients |
| objective coefficients `c` | limits |
| `A` | `Aᵀ` |
| max, `≤` | min, `≥` |

This table is valid only under the form's two assumptions, every constraint a `≤` and every
variable `≥ 0`. Those are the features the three requirements relied on. The next concept
relaxes both.

> For max `cᵀx` with `Ax ≤ b`, `x ≥ 0`, the dual is min `bᵀy` with `Aᵀy ≥ c`, `y ≥ 0`.
> The matrix is transposed and `b` and `c` trade places.
