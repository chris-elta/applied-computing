Split `A`'s coefficients by parity into two polynomials of roughly half the degree:

```
A(x) = A_even(x²) + x · A_odd(x²)
```

Check it on `A(x) = 1 + 2x + 3x²`: here `A_even(y) = 1 + 3y` (the even-indexed coefficients,
`a_0` and `a_2`) and `A_odd(y) = 2` (the one odd-indexed coefficient, `a_1`), and
`(1 + 3x²) + x·2` is `A(x)` again.

This identity is true for **any** `x` whatsoever — it's just regrouping the same terms. What
makes it useful is what happens next: `x²` runs over only half as many distinct values as `x`
does, and that's exactly the redundancy the roots of unity were built to exploit.
