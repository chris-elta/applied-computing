QuickSort is a divide-and-conquer sorting algorithm built on one idea:

- choose a **pivot** — an element of the array (how? — that question is worth holding on to);
- **partition** the array so everything smaller than the pivot goes left, everything larger
  goes right;
- recursively QuickSort the left and right subarrays;
- combine — free, since the pieces are already in the right order relative to each other.

## The selection algorithm

A linear-time selection algorithm follows almost the same template:

1. choose a **random** pivot element;
2. **partition** the input array around the pivot;
3. recurse **appropriately**.

Two words in that list are doing all the work. **Random** is what will make the running-time
analysis possible — not because randomness is needed for correctness, but because it is what
lets an average-case argument be made about *any* input, without assuming anything about the
data itself. **Appropriately** is the payoff: QuickSort recurses into both halves, because
sorting needs the whole array in order. Selection only wants one rank, `k`, and that rank sits
entirely inside one half of the partition — so only one recursive call is needed, not two.
That single difference, one call instead of two, is worth an entire exponent by the time the
master theorem is applied to it.
