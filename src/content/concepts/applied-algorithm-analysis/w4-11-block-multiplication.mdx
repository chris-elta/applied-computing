Cut each matrix into four `n/2 × n/2` blocks. The product obeys the same rule, one block at a
time:

```
X = [A B]   Y = [E F]   XY = [AE+BG  AF+BH]
    [C D]       [G H]        [CE+DG  CF+DH]
```

Eight products of half-size matrices, plus `O(n²)` work to add the results together:

```
T(n) = 8 T(n/2) + O(n²)
```

Master theorem: `a=8, b=2, d=2`. Since `log₂8 = 3 > 2 = d`, the leaves pay:

```
T(n) = O(n^log₂8) = O(n³)
```

**Exactly the cost of the definition.** Splitting a problem up is not, by itself, a saving —
the same lesson landed when four half-size integer products came to `O(n²)` again, with no
improvement over the schoolbook method. The parallel is exact: the naive integer split had
ratio `4/2¹ = 2`; this block split has ratio `8/2² = 2`. Same number, both times, and it's
exactly why Karatsuba needed a three-product identity to make integer multiplication faster —
and exactly what motivates the search for a seven-product identity here.
