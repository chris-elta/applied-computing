**Supervised learning** trains a model on a **labelled** data set: input–output pairs where
the right answer is known for every example. The goal is to **learn the mapping from inputs
to outputs**, so the model can produce the output for inputs it has never seen.

## How it runs

The lecture draws two passes:

| Pass | Flow |
| --- | --- |
| **Training** | Input data → feature extraction → **feature vectors**, plus **labels** → ML algorithm |
| **Prediction** | New input data → feature extraction → feature vectors → **predictive model** → **predicted labels** |

**Feature extraction** turns raw input into numbers the algorithm can use. An email becomes a
**feature vector**: a list of measurements such as word counts, number of links and whether
the sender is known. The same extraction is applied in both passes, so the model sees new
inputs described the same way as its training data.

## Two kinds of output

| | Classification | Regression |
| --- | --- | --- |
| **Predicts** | A category or label | A continuous value |
| **Example** | Spam or not spam | Forecast stock performance |

The lecture's decision tree starts with one question, **are the labels discrete?**

- **Yes → classification.** The slide shows linear classifiers, SVM (support vector machine),
  KNN (k-nearest neighbours), decision trees, naïve Bayes and logistic regression.
- **No → regression.** Linear and nonlinear regression.

Logistic regression is a trap in the name. Despite "regression", it predicts a **category**:
it estimates the probability that an example belongs to a class.

## Pros and cons

| Pros | Cons |
| --- | --- |
| High accuracy **when sufficient labelled data is available** | **Requires large labelled data sets**, which are expensive to create |
| Well-understood algorithms and metrics | Can **overfit** if not regularised |
| Works well for prediction tasks | Performance **depends heavily on data quality** |

The first pro carries a condition, and the first con is the price of meeting it. Someone has
to label every training example. For spam, users do it by clicking a button. For medical
scans, it takes a specialist's time, which is the gap *Semi-Supervised Learning* addresses.

"Depends heavily on data quality" connects to *Bias in ML Data*. A model learns whatever the
labels say, so systematic mistakes in labelling become systematic mistakes in prediction.
**Overfitting** — learning the training set's noise instead of its pattern — is covered in
*Overfitting and Other Design Issues*.

> Supervised learning copies the answers it is shown. It is only as good, and as fair, as the
> labels behind it.
