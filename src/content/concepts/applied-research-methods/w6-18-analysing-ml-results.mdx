The lecture gives four instructions for analysing results:

1. **Use metrics**: accuracy, precision, recall, F1-score, ROC-AUC.
2. **Visualise** with confusion matrices and ROC curves.
3. **Interpret results in the context of research goals and limitations.**
4. **Validate findings with domain experts.**

## The confusion matrix

For a classifier with two classes, every prediction falls into one of four cells:

| | Actually spam | Actually not spam |
| --- | --- | --- |
| **Predicted spam** | TP (true positive) | FP (false positive) |
| **Predicted not spam** | FN (false negative) | TN (true negative) |

Every metric is a ratio of these cells.

| Metric | Formula | Asks |
| --- | --- | --- |
| **Accuracy** | (TP + TN) / all | How often is it right? |
| **Precision** | TP / (TP + FP) | When it says spam, how often is it spam? |
| **Recall** | TP / (TP + FN) | Of all the spam, how much did it catch? |
| **F1** | 2 × precision × recall / (precision + recall) | Both at once |

## A worked example

1,000 emails, 100 of them spam. The filter flags 90, of which 80 are spam.

- TP = 80, FP = 10, FN = 100 − 80 = 20, TN = 1000 − 80 − 10 − 20 = 890
- Accuracy = (80 + 890) / 1000 = **0.97**
- Precision = 80 / 90 = **0.89**
- Recall = 80 / 100 = **0.80**
- F1 = 2 × 0.89 × 0.80 / (0.89 + 0.80) ≈ **0.84**

Now a filter that marks **nothing** as spam: accuracy = 900 / 1000 = **0.90**, recall = **0**.
Accuracy alone ranks a useless filter only seven points behind a good one. When one class is
rare, accuracy mostly measures how common the other class is.

## Choosing the metric from the goal

Which metric matters depends on which mistake costs more. A spam filter that bins a job offer
(FP) is worse than one that lets an advert through (FN), so precision matters. A cancer
screen that misses a tumour (FN) is worse than a false alarm (FP), so recall matters. This is
*Be Your Own Reviewer*'s "metrics derived from the goal".

**ROC-AUC** sidesteps the choice of threshold. It summarises performance across every
threshold, with 0.5 meaning chance.

## Context and experts

A score is not a finding. **Interpreting in context** means asking whether it answers the
research question, and what the limitations allow you to claim. **Validating with domain
experts** checks whether the patterns make sense, which matters most for unsupervised
results that have no accuracy score at all.

> Pick the metric from the cost of each mistake. Accuracy on a rare class tells you how rare
> it is.
