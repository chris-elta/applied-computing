Two numbers do the work in a significance test.

## The test statistic

The **test statistic** is a convenient summary of the sample data that can be used to decide
between the hypotheses. It is often a transformation of the data to a more convenient form,
such as a **z-score**, and it is **calculated assuming `H₀` is true**. You can read it as *how
many standard deviations away from the null value the sample was*.

For a mean with known `σ`:

`z = (x̄ − μ₀) / (σ/√n)`

The numerator is the gap between what you saw (`x̄`) and what the null claims (`μ₀`). The
denominator is the standard deviation of a sample mean, the same quantity that sets the
margin of error in a confidence interval.

For example, if `H₀: μ = 100`, `σ = 15`, `n = 36` and the sample mean is 106, then
`z = 6 / 2.5 = 2.4`: the sample sits 2.4 standard errors above the null value.

## The p-value

The **p-value** is a probability, so a number between 0 and 1. It measures **how consistent
the sample data are with the null hypothesis**. The lecture offers two phrasings:

- the probability of observing a value of the test statistic **as extreme or more extreme**
  than the one observed, **if `H₀` is true**;
- the probability of observing **data like ours** if the null hypothesis is true.

It is found from the normal curve: the area in the tail beyond the test statistic. A small
p-value says that data like yours would be rare in a world where the null is true, which is
reason to doubt that world.

## What it is not

The p-value is **not** the probability that the null hypothesis is true. Every p-value is
computed *by assuming the null*; it cannot then tell you how likely that assumption is. This is
the same trap as the confidence-interval one: a probability about data under a hypothesis is
not a probability about the hypothesis.

> A p-value answers 'how surprising is this sample, if nothing is going on?'. It does not answer
> 'is something going on?'.
