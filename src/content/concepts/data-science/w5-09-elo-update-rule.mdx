A beginner beats another beginner. Separately, a beginner beats a grandmaster. Each of those
is one win. Should both winners move up the ladder by the same amount?

Clearly not. The first result tells you almost nothing new. The second tells you that your
ranking was wrong about someone. Elo is a rating system built on that difference. The slide
puts it this way: **after starting equally ranked, scores are then adjusted to reflect the
surprise of each match.**

## The update rule

```
r′(A) = r(A) + k · (S_A − μ_A)
```

Reading from the left:

- `r(A)` is A's rating before the match and `r′(A)` is the rating after it.
- `S_A` is what happened: on this slide, `1` if A won and `−1` if A lost.
- `μ_A` is what the ratings predicted would happen, the *expected score*.
- `S_A − μ_A` is the **surprise**: actual minus expected.
- `k` is a dial. The slide says it **modulates the maximum possible swing in any one
  match.**

So the new rating is the old rating plus `k` times the surprise. If the result matches the
prediction, the bracket is near zero and little changes. If the result contradicts the
prediction, the bracket is large and the rating moves a long way.

## The expected score

To use the rule you need `μ_A`. Suppose you have an estimate `P(A>B)` of the probability that
A beats B. A match scores `+1` with that probability and `−1` otherwise, so the average
score over many such matches is

```
μ_A = 1 · P(A>B) + (−1) · (1 − P(A>B))
```

Three cases:

| `P(A>B)` | `μ_A` | meaning |
| --- | --- | --- |
| 0.5 | `0.5 − 0.5 = 0` | Evenly matched |
| 0.9 | `0.9 − 0.1 = 0.8` | A is a strong favourite |
| 0.1 | `0.1 − 0.9 = −0.8` | A is a heavy underdog |

## The surprise at work

Take the favourite, with `μ_A = 0.8`, and `k = 10`.

- A wins: `10 × (1 − 0.8) = +2`.
- A loses: `10 × (−1 − 0.8) = −18`.

Win counts could not do this. The favourite gains little from winning and loses a lot from
losing, and the underdog's numbers are the mirror image. Beating a strong opponent now
counts for more than beating a weak one, and nobody had to label opponents as strong or weak
by hand. The ratings carry that information.

## What is still missing

Where does `P(A>B)` come from? The slide gives a condition: **if the ranking system is
meaningful, this probability should be a function of the difference between the scores
`r(A)` and `r(B)`.** A larger rating gap should mean a more lopsided match. The next concept
finds a function that does this.

> Elo moves a rating by the surprise, actual minus expected. An expected result changes
> little and an upset changes a lot.
