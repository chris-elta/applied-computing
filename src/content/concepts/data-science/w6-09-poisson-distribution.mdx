A call centre receives on average 4 calls per hour. Calls come from many people, each of
whom is unlikely to call in any given hour. How likely is an hour with exactly 6 calls?

## Rare events, counted

This is the setting from the end of the previous section: **many opportunities, each with a
small chance**. The binomial formula would need the number of potential callers and each
one's probability, and you know neither. You know only the average. The Poisson
distribution needs nothing else.

The slide says it **measures the frequency of intervals between rare events**. In practice
that means counting how many events land in a fixed interval: calls per hour, typos per
page, failures per month.

```
Pr(x) = e⁻ᵘ μˣ / x!
```

## Parameterized by the mean

The slide: **instead of event probability `p`, it is parameterized by mean `μ`**, which is
equivalent because

```
μ = Σ k · Pr(k)   (sum over k = 0, 1, 2, …)
```

That sum is the definition of a mean, the average of every count weighted by its
probability. The point is that `μ` alone fixes the distribution. You do not need to know how
many potential callers there are, only how many calls arrive on average.

## The call centre

The slide's example, with `μ = 4` and `x = 6`:

```
Pr(6) = e⁻⁴ × 4⁶ / 6!
      = 0.0183 × 4096 / 720
      ≈ 0.104
```

About a 10.4% chance of exactly 6 calls. Some other values:

| calls | probability |
| --- | --- |
| 0 | `e⁻⁴` ≈ 0.018 |
| 4 | ≈ 0.195 |
| 6 | ≈ 0.104 |

## Spread

The slide's last line is **the Poisson distribution is normal with `σ = μ`.** The idea is
right but the formula is off by a square root. A Poisson's **variance** equals its mean, so
its standard deviation is `σ = √μ`. For the call centre, `σ = 2`. With a large mean the
Poisson looks like a normal curve with that spread, by the same reasoning that made the
binomial normal.

This makes a quick test. If a count is supposed to be Poisson but its variance is much bigger
than its mean, something else is going on: events arriving in bursts, or a rate that changes
over time.

> Poisson: counts of rare, independent events in an interval, set entirely by the average
> `μ`. Variance equals the mean, so `σ = √μ`.
