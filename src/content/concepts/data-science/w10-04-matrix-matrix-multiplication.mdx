Matrix–matrix multiplication is matrix–vector multiplication done several times side by side.

## The rule

Multiply an `m × n` matrix `A` by an `n × o` matrix `B`, and you get an `m × o` matrix `C`
(slide 16):

> The i-th column of the matrix C is obtained by multiplying A with the i-th column of B.

So split `B` into its columns, multiply `A` by each one using the previous concept's rule, and
stand the resulting vectors side by side.

## A worked example

Slide 15:

```
⎡ 1  3  2 ⎤   ⎡ 1  3 ⎤
⎣ 4  0  1 ⎦ × ⎢ 0  1 ⎥
              ⎣ 5  2 ⎦
```

Column 1 of `B` is `[1, 0, 5]`:

```
row 1: 1×1 + 3×0 + 2×5 = 11
row 2: 4×1 + 0×0 + 1×5 =  9
```

Column 2 of `B` is `[3, 1, 2]`:

```
row 1: 1×3 + 3×1 + 2×2 = 10
row 2: 4×3 + 0×1 + 1×2 = 14
```

So:

```
⎡ 11  10 ⎤
⎣  9  14 ⎦
```

`2 × 3` times `3 × 2` gives `2 × 2`. Equivalently, entry `Cᵢⱼ` is row `i` of `A` times column
`j` of `B`.

## The dimension check

```
(m × n) × (n × o) = (m × o)
      └─────┘
     must match
```

`A` must have as many columns as `B` has rows. Otherwise the product is undefined.

## The trick: three hypotheses at once

Slide 18 extends the house-price example. You have three competing models:

| | hypothesis |
| --- | --- |
| 1 | `hθ(x) = −40 + 0.25x` |
| 2 | `hθ(x) = 200 + 0.1x` |
| 3 | `hθ(x) = −150 + 0.4x` |

Put each model's parameters in a column, and multiply once:

```
⎡ 1  2104 ⎤                           ⎡ 486  410  692 ⎤
⎢ 1  1416 ⎥   ⎡ −40   200  −150 ⎤     ⎢ 314  342  416 ⎥
⎢ 1  1534 ⎥ × ⎣ 0.25  0.1   0.4 ⎦  =  ⎢ 344  353  464 ⎥
⎣ 1   852 ⎦                           ⎣ 173  285  191 ⎦
```

Each **column** of the result is one model's predictions for all four houses (the slide
rounds to whole numbers). Twelve predictions, one product, and linear-algebra libraries are
heavily optimised for exactly this kind of product.

> An m × n matrix times an n × o matrix gives an m × o matrix, each column being A times one
> column of B. Put the data in one matrix and several models' parameters in the other, and you
> get every model's predictions at once.
