Regularisation keeps every feature but makes the cost function charge for large parameters.

## The intuition

Slide 42 compares a quadratic and a quartic fit to the same house prices. The quartic overfits.
Suppose you change the cost to

```
min over θ:   (1/2m) Σ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾)²  +  1000·θ₃²  +  1000·θ₄²
```

Now any non-zero θ₃ or θ₄ is very expensive. The cheapest solution makes θ₃ and θ₄ really small,
and the quartic becomes, in effect, the quadratic: still technically four terms, but the two that
caused the wiggles barely contribute.

## Small parameters, simpler hypothesis

Slide 43 generalises. Small values for the parameters θ₀, θ₁, …, θₙ give

- a **"simpler" hypothesis**: smoother, with fewer sharp turns;
- one **less prone to overfitting**.

With 100 features you do not know in advance which parameters to shrink. So shrink them all.

## The regularised cost

Slide 44:

```
J(θ) = (1/2m) [ Σᵢ₌₁ᵐ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾)²  +  λ Σⱼ₌₁ⁿ θⱼ² ]
```

and the goal is still `minimise J(θ)`.

| term | job |
| --- | --- |
| `Σ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾)²` | fit the training data |
| `λ Σ θⱼ²` | keep the parameters small |
| `λ` | how much to care about the second goal relative to the first |

Note that the penalty sum starts at **j = 1**. θ₀ is not penalised. It sets the overall level of
predictions, which has nothing to do with how wiggly the curve is.

## Choosing λ

λ trades off the two terms, so it is a dial between week 9's two failures:

| λ | effect | result |
| --- | --- | --- |
| 0 | no penalty | ordinary regression; the quartic overfits |
| moderate | large θs cost something | a smoother curve that still fits |
| far too large, such as 10¹⁰ | every θⱼ forced to ≈ 0 | `hθ(x) ≈ θ₀`, a flat line: underfit |

Slide 45 asks the last case directly. With an enormous λ, the penalty swamps the fit, so θ₁ to θ₄
all go to nearly zero. Only θ₀ survives, and the hypothesis is a horizontal line at about the average
price, which misses the trend completely.

So λ must be chosen, and the training cost cannot choose it: λ = 0 always gives the lowest training
cost. Choose λ by performance on held-out data: the testing set or cross-validation from week 9.

> Regularisation adds λ times the sum of squared parameters (from θ₁) to the cost. It shrinks the
> parameters toward zero, smoothing the fit. λ = 0 risks overfitting; λ huge flattens the model; pick
> it on held-out data.
