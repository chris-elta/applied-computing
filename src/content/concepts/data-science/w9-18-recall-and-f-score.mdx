Precision asked how many of the model's positives were real. **Recall** asks the opposite
question: of the real positives, how many did the model find?

## Recall

```
recall = TP / (TP + FN)
```

Slide 73 grounds it in the cancer case: "we would tolerate some false positives (scares) to
identify real cases". Recall measures being right on positive instances. In the screening
example (TP = 40, FN = 10):

```
recall = 40 / (40 + 10) = 0.80
```

The model finds 80% of the cancers.

The two measures differ only in their denominator, and that is the whole distinction:

| measure | question | divides by |
| --- | --- | --- |
| precision | when it says yes, is it right? | everything it **called** positive: TP + FP |
| recall | of the real yeses, how many did it catch? | everything that **is** positive: TP + FN |

Recall has its own cheat, which slide 73 names: **saying everyone has cancer gives perfect
recall**. TP = 50, FN = 0, recall = 1. Precision collapses to 5%. Each measure alone can be
gamed, in opposite directions, and the threshold from the four-outcomes concept is the dial:
lower it and recall rises while precision falls.

## The F-score

To get one meaningful number that balances both, slide 74 uses the **F-score**:

```
F = 2 × precision × recall / (precision + recall)
```

This is the **harmonic mean** of the two. For the screening model:

```
F = 2 × 0.40 × 0.80 / (0.40 + 0.80) = 0.64 / 1.20 ≈ 0.53
```

Why harmonic and not the ordinary average? Because "the harmonic mean is always less than or
equal to the arithmetic mean, making it tough to get a high F-score". It is pulled toward the
smaller number. Try the cheats:

| model | precision | recall | ordinary average | F |
| --- | --- | --- | --- | --- |
| always says cancer | 0.05 | 1.00 | 0.53 | 0.10 |
| the screening model | 0.40 | 0.80 | 0.60 | 0.53 |

The ordinary average rates the always-yes model nearly as highly as the real one, 0.53 against
0.60. The F-score gives it 0.10: one terrible number sinks it.

## Take-away lessons

From slide 75:

- Accuracy is misleading when class sizes are substantially different.
- High precision is very hard to achieve with unbalanced class sizes.
- The F-score does the best job of any single statistic, **but all four work together** to
  describe the performance of a classifier.

Report accuracy, precision, recall and F together, and say which error your application
cares about more.

> Precision divides by what you predicted; recall by what was there. Each can be gamed alone.
> The F-score, a harmonic mean, is high only when both are.
