The last two operations in the review both appear in the **normal equation**, later this
week, which solves linear regression in one formula: `θ = (XᵀX)⁻¹Xᵀy`.

## The inverse

With numbers, most have a reciprocal: `3 × 3⁻¹ = 1`. "Not all numbers have an inverse"
(slide 24): zero does not.

For an `m × m` matrix `A`, an inverse `A⁻¹` is a matrix such that

```
A × A⁻¹ = A⁻¹ × A = I
```

where `I` is the identity from the previous concept. For example:

```
⎡ 3   4 ⎤ ⎡  0.4    −0.1  ⎤   ⎡ 1  0 ⎤
⎣ 2  16 ⎦ ⎣ −0.05   0.075 ⎦ = ⎣ 0  1 ⎦
```

Check the top-left entry: `3 × 0.4 + 4 × (−0.05) = 1.2 − 0.2 = 1`.

Three facts:

- **only square matrices** can have an inverse in this sense;
- **some square matrices have none.** Slide 24: matrices that do not have an inverse are
  **singular** or **degenerate**. The all-zero matrix is the obvious one; so is
  `[[1, 2], [2, 4]]`, whose second row is just twice the first;
- you do not compute inverses by hand in this course. Software does it: `np.linalg.inv`, or
  `pinv`, which copes with the singular case.

That last pair matters for regression. The normal-equation concept shows when `XᵀX` turns out
singular: when one feature is a multiple of another, just like the rows here.

## The transpose

The **transpose** flips a matrix over its diagonal, so rows become columns (slide 25):

```
       ⎡ 1  2  0 ⎤              ⎡ 1  3 ⎤
A  =   ⎣ 3  5  9 ⎦      Aᵀ  =   ⎢ 2  5 ⎥
                                ⎣ 0  9 ⎦
```

If `A` is `m × n`, then `B = Aᵀ` is `n × m`, and

```
Bᵢⱼ = Aⱼᵢ
```

Every matrix has a transpose; no conditions.

The transpose's most common use in these lectures is turning a column into a row so that two
vectors can be multiplied. With `θ` and `x` both columns, `θᵀx` is a `1 × n` row times an
`n × 1` column: a single number, the sum of `θᵢxᵢ`. That is exactly how the multi-feature
hypothesis is written.

> A⁻¹ undoes A: their product is the identity. Only square matrices can have one, and some
> (singular ones) do not. Aᵀ swaps rows and columns, and exists for every matrix.
