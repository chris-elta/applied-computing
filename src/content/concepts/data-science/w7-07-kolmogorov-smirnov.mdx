The t-test asks one narrow question: do two groups have different *means*? Sometimes you want
to know something broader. The speaker notes give an example: compare this year's test scores
with last year's. Did performance change overall, not only on average but in the **whole
distribution**?

## Comparing CDFs

The **Kolmogorov-Smirnov (KS) test** measures whether two samples are drawn from the same
distribution, using the CDFs from week 2.

For each sample, build its **empirical CDF**: for any value `x`, the fraction of the sample
at or below `x`. It is a staircase climbing from 0 to 1. On slide 16, red is one sample's
staircase and blue is the other's.

If both samples came from the same distribution, the staircases should run close together.
So the test slides along every possible `x` and finds **the largest vertical gap between
them**. That gap, the black arrow on the slide, is the KS statistic:

```
D = sup |F₁,ₙ(x) − F₂,ₙ′(x)|
     x
```

Read `sup` as "the largest over all `x`".

## When the gap is big enough

The distributions differ, at significance level `α`, if

```
D > c(α) · √( (n + n′) / (n · n′) )
```

The square root shrinks as the samples grow, so bigger samples need a smaller gap to be
convincing. `c(α)` is looked up in a table; for `α = 0.05` it is about 1.36.

For example, with two samples of 50:

```
√( (50 + 50) / (50 × 50) ) = √(100 / 2500) = √0.04 = 0.2
threshold = 1.36 × 0.2 ≈ 0.27
```

The CDFs must differ by more than 0.27 somewhere, roughly a quarter of the data, before you
reject `H₀`.

## Why it is useful

- **It makes no assumption about shape.** The t-test leans on normality; the KS test works for
  any distribution. The notes call it *non-parametric*.
- **It sees any kind of difference.** A shift in centre, a change in spread or a change in
  shape all open a gap between the CDFs.

## Testing for normality

Slide 17 uses the KS test to ask whether data *is* normal. Compare the data with a sample
drawn from the theoretical distribution:

- **normal vs uniform** (left): the curves pull apart, with a large gap. Not the same.
- **normal vs normal** (right): the curves track each other closely. Consistent with the
  same distribution.

This matters because the t-test and the 68–95–99.7 rule from last week both assume normality.
The KS test is one way to check that assumption instead of trusting it.

> The KS test compares two whole distributions by the biggest gap between their CDFs. It
> assumes no particular shape, so it is also a way to check whether data is normal.
