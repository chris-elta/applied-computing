This is the operation that makes regression fast: one multiplication computes a prediction
for every house at once.

## The rule

Multiply an `m × n` matrix `A` by an `n`-dimensional vector `x`, and you get an
`m`-dimensional vector `y` (slide 11):

> To get yᵢ, multiply A's i-th row with the elements of vector x, and add them up.

Each row of `A` is paired with `x` element by element, multiplied, and summed into one number.
One row, one output.

## A worked example

Slide 10:

```
⎡ 1  3 ⎤           ⎡ 1×1 + 3×5 ⎤   ⎡ 16 ⎤
⎢ 4  0 ⎥ × ⎡ 1 ⎤ = ⎢ 4×1 + 0×5 ⎥ = ⎢  4 ⎥
⎣ 2  1 ⎦   ⎣ 5 ⎦   ⎣ 2×1 + 1×5 ⎦   ⎣  7 ⎦
```

`3 × 2` times `2 × 1` gives `3 × 1`.

## The dimension check

The inner numbers must agree, and the outer ones give the result's shape:

```
(m × n) × (n × 1) = (m × 1)
      └─────┘
     must match
```

The matrix needs as many **columns** as the vector has **entries**, because each row is paired
entry by entry with `x`. If they differ, the product is undefined.

## The trick: predictions as a product

Slide 13 shows why this matters. Four house sizes, and a model predicting price from size:

```
hθ(x) = −40 + 0.25x
```

You could compute four predictions one at a time. Instead, put a column of 1s beside the
sizes and the two parameters in a vector:

```
⎡ 1  2104 ⎤                ⎡ −40 + 0.25 × 2104 ⎤   ⎡ 486   ⎤
⎢ 1  1416 ⎥ × ⎡ −40  ⎤  =  ⎢ −40 + 0.25 × 1416 ⎥ = ⎢ 314   ⎥
⎢ 1  1534 ⎥   ⎣ 0.25 ⎦     ⎢ −40 + 0.25 × 1534 ⎥   ⎢ 343.5 ⎥
⎣ 1   852 ⎦                ⎣ −40 + 0.25 × 852  ⎦   ⎣ 173   ⎦
```

The column of 1s is what makes this work: each row computes `1 × (−40) + size × 0.25`, which
is the hypothesis. The prediction is now one line of code, `X @ theta` in NumPy, which runs far
faster than a loop and reads like the maths.

That column of 1s comes back in the multi-feature regression lectures as `x₀ = 1`.

> An m × n matrix times an n-vector gives an m-vector: each output entry is one row times the
> vector, multiplied entry by entry and summed. Put the data in a matrix and the parameters in
> a vector, and every prediction comes out at once.
