The PageRank formula is easier to understand by running it on a small graph. The slide uses
three pages.

```
A → B
B → C
C → A, B
```

Before computing, turn that list around. The formula asks who links *to* a page, not who it
links to.

| page | linked to by | out-degree of each linker |
| --- | --- | --- |
| A | C | C has 2 links |
| B | A and C | A has 1 link, C has 2 |
| C | B | B has 1 link |

Getting this table wrong is the usual way to get PageRank wrong.

## Step 0: start equal

```
PR₀(A) = PR₀(B) = PR₀(C) = 1/3 ≈ 0.33
```

## Step 1: one iteration

Every new score is computed from the **old** scores. Do not use a value you have just
updated in the same round.

**Page A.** Only C links to A, and C has two outgoing links.

```
PR(A) = PR(C)/2 = 0.33/2 = 0.165
```

**Page B.** A and C both link to B. A has one outgoing link, so B gets all of A's score. C
has two, so B gets half of C's.

```
PR(B) = PR(A)/1 + PR(C)/2 = 0.33 + 0.165 = 0.495
```

**Page C.** Only B links to C, and B has one outgoing link.

```
PR(C) = PR(B)/1 = 0.33
```

## Check: the total

`0.165 + 0.495 + 0.33 = 0.99`, which is 1 apart from rounding 1/3 to 0.33. That is expected.
Each page hands out its whole score, split among its links, so score moves around and is
neither created nor destroyed. The scores are probabilities of where the walker is, and they
have to total 1. If your scores do not sum to 1 after a round, look for a link you counted
twice or missed.

## Keep going

The slide stops after one round. The algorithm does not, so here are the next rounds, in
exact fractions.

| round | A | B | C |
| --- | --- | --- | --- |
| 0 | 1/3 | 1/3 | 1/3 |
| 1 | 1/6 | 1/2 | 1/3 |
| 2 | 1/6 | 1/3 | 1/2 |
| 3 | 1/4 | 5/12 | 1/3 |
| … | … | … | … |
| steady state | 0.2 | 0.4 | 0.4 |

You can confirm the last row without iterating. Put those values into the formula and they
come back unchanged: `A = C/2 = 0.2`, `B = A + C/2 = 0.2 + 0.2 = 0.4`, `C = B = 0.4`.

## Reading the result

After one round B looked like the clear leader. At the steady state B and C are level. C has
only one page linking to it, but that page is B, and B passes on everything it has. A comes
last because its one incoming link is half of C's attention.

So the first iteration is not the answer. It counts direct links only. Later rounds let
importance travel further through the graph, and the ranking can change along the way.

> For each page, list who links to it, divide each linker's old score by its out-degree, and
> add. Repeat until the numbers stop moving.
