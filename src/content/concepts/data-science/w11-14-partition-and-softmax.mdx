One-vs-all left a loose end. Its classifiers are trained independently, and slide 22 says it
plainly: there is no reason why independent binary classifiers yield probabilities which sum
to 1. If you need real probabilities, for instance to combine with other evidence through
Bayes' theorem, the outputs have to be repaired.

## Dividing by the total

The direct fix is to add up all the outputs and divide each by the sum:

```
T = Σ F_i(x)  over all classes i          P(c) = F_c(x) / T
```

`T` is called the **partition function**. Take three classifiers with outputs 0.9, 0.6 and
0.3:

| class | `F_c(x)` | `P(c) = F_c(x) / 1.8` |
| --- | --- | --- |
| A | 0.9 | 0.50 |
| B | 0.6 | 0.33 |
| C | 0.3 | 0.17 |

`T = 1.8`, and the right-hand column sums to 1. The order of the classes is unchanged, so the
predicted label is the same as before. Only the scale moved. Slide 23 calls this **standard
normalisation**.

## Softmax

The slide's alternative is **softmax**. Raise `e` to each score first, then normalise:

```
softmax(z)ᵢ = e^zᵢ / Σ e^zⱼ
```

The exponential makes every term positive, so softmax accepts any scores, including negative
ones. It also exaggerates gaps. For the scores `[1, 2]`:

```
e¹ ≈ 2.718    e² ≈ 7.389    total ≈ 10.107
softmax = [2.718 / 10.107, 7.389 / 10.107] ≈ [0.27, 0.73]
```

## The comparison on slide 23

The slide runs both methods on two inputs. The first is described as a blurry image of a
ferret, where the network is barely activated. The second is a crisp image of a cat with
scores ten times larger.

| scores | standard normalisation | softmax |
| --- | --- | --- |
| `[1, 2]` | `[0.33, 0.67]` | `[0.27, 0.73]` |
| `[10, 20]` | `[0.33, 0.67]` | `[0.00005, 0.99995]` |

Standard normalisation gives the same answer both times, "it is a cat perhaps", because
`1:2` and `10:20` are the same ratio. Softmax tells them apart. A gap of 1 between scores
gives mild confidence, and a gap of 10 gives near certainty: "it is definitely a cat".

Softmax responds to **differences** between scores and standard normalisation to **ratios**.
When stronger evidence shows up as larger scores, softmax is the one that reflects it.

The same property is a hazard. Softmax will report 99.995% from any sufficiently large gap,
whether or not the scores deserve that trust.

> Independent classifiers' outputs must be normalised to act as probabilities. Dividing by
> the total preserves ratios. Softmax exponentiates first, so larger gaps between scores
> become sharper confidence.
