Two operations work entry by entry, with nothing new to learn.

## Addition

To add two matrices, add the entries in matching positions (slide 6):

```
⎡ 1  0 ⎤   ⎡ 4  0.5 ⎤   ⎡ 5  0.5 ⎤
⎢ 2  5 ⎥ + ⎢ 2  5   ⎥ = ⎢ 4  10  ⎥
⎣ 3  1 ⎦   ⎣ 0  1   ⎦   ⎣ 3  2   ⎦
```

This only works when the two matrices have **the same dimension**. Slide 6's second example
adds a 3 × 2 matrix to a 2 × 2 one: there is no entry to pair with the third row, so the sum is
**undefined**. Not zero, not padded: it does not exist.

## Scalar multiplication

A **scalar** is a single number. Multiplying a matrix by a scalar multiplies **every entry**
(slide 7):

```
    ⎡ 1  0 ⎤   ⎡ 3   0 ⎤
3 × ⎢ 2  5 ⎥ = ⎢ 6  15 ⎥
    ⎣ 3  1 ⎦   ⎣ 9   3 ⎦
```

Dividing by a scalar is multiplying by its reciprocal:

```
⎡ 4  0 ⎤          ⎡ 1    0   ⎤
⎣ 6  3 ⎦ / 4  =   ⎣ 1.5  0.75⎦
```

Order does not matter: `3 × A` is the same as `A × 3`.

## Combining them

Slide 8 chains the operations on column vectors. The usual order of operations applies:
multiplications and divisions first, then additions and subtractions.

```
3 × [1, 4, 2] + [0, 0, 5] − [3, 0, 2] / 3
  = [3, 12, 6] + [0, 0, 5] − [1, 0, 2/3]
  = [2, 12, 31/3]
```

## Why it matters for regression

Gradient descent, later this week, updates all the parameters at once with a line of the form

```
θ := θ − α × (a vector of slopes)
```

That is a scalar multiplication followed by a subtraction of two vectors of the same length,
exactly the operations on this page.

> Add or subtract matrices entry by entry, only when their dimensions match. Multiply by a
> scalar by multiplying every entry.
