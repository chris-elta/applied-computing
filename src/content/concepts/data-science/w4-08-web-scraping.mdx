**Scraping** is the fine art of stripping text and data from a web page. Python has libraries
for it — **BeautifulSoup** parses a page's HTML, and **Selenium** drives a real browser for
pages that need it.

The lecture's advice is to search before you scrape:

1. **Are APIs available from the source?** An API returns structured data on purpose and is
   far less fragile than parsing a layout that can change tomorrow.
2. **Did someone previously write a scraper?** Reusing one saves the work and the bugs.

Then comes the constraint: **terms of service limit what you can legally do.** Being able to
fetch a page does not mean you are allowed to collect it.

> Scraping is the last resort among the web options, not the first. Look for an API, then
> for existing code, then read the terms.
