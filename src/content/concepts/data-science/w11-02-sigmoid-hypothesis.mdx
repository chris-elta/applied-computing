We want a hypothesis that never leaves the range 0 to 1. The move on slide 6 is small: keep
the weighted sum from linear regression, then pass it through a function that squashes any
number into that range.

```
hθ(x) = g(θᵀx)        where  g(z) = 1 / (1 + e⁻ᶻ)
```

`g` is the **sigmoid function**, also called the **logistic function**. Put together:

```
hθ(x) = 1 / (1 + e^(−θᵀx))
```

## What the sigmoid does

Try a few values of `z`:

| `z` | `e⁻ᶻ` | `g(z)` |
| --- | --- | --- |
| −5 | 148.4 | 0.007 |
| −2 | 7.39 | 0.119 |
| 0 | 1 | 0.5 |
| 2 | 0.135 | 0.881 |
| 5 | 0.007 | 0.993 |

Very negative `z` makes `e⁻ᶻ` enormous, so the fraction is near 0. Very positive `z` makes
`e⁻ᶻ` vanish, so the fraction is near 1. In between, the curve rises smoothly in an S shape
through 0.5 at `z = 0`. It gets close to 0 and 1 and never reaches either.

This repairs both failures of the straight line. The output cannot escape the range, and a
very large tumour only pushes `z` further right, where the curve is already flat at 1. Easy
examples stop dragging the model around.

## Reading the output

Slide 7 gives the number a meaning: `hθ(x)` is the **estimated probability that `y = 1`** for
input `x`.

The slide's example has features `x₀ = 1` and `x₁ = tumorSize`. If `hθ(x) = 0.7`, you tell
the patient there is a 70% chance the tumour is malignant. Formally:

```
hθ(x) = P(y = 1 | x; θ)
```

Because `y` must be 0 or 1, the two probabilities sum to 1:

```
P(y = 0 | x; θ) = 1 − P(y = 1 | x; θ)
```

So a single output covers both classes.

Linear regression's `θᵀx` has not gone anywhere. It is now an intermediate score, and the
sigmoid converts that score to a probability.

> Logistic regression is linear regression's weighted sum passed through the sigmoid. The
> result is always between 0 and 1 and is read as the probability of the positive class.
