The Elo update needs a number that the last concept left open: the probability that A beats
B, given their two ratings. The slide before required it to depend only on the rating
difference. So you need a machine that takes a difference, which can be any number, positive
or negative, and returns a probability, which must lie between 0 and 1.

## Requirements first

Before looking for a formula, write down what it has to do. The slide lists three things for
a function `f(x)` that takes `x` and gives a probability.

| requirement | in words |
| --- | --- |
| `f(0) = ½` | Equal ratings: a coin flip |
| `f(∞) = 1` | A vastly stronger player is almost sure to win |
| `f(−∞) = 0` | A vastly weaker player is almost sure to lose |

One more is implied: the function should rise smoothly in between, so that a bigger gap
always means a better chance.

## A straight line fails

The obvious candidate is a line through `(0, ½)` with an upward slope. Follow it far enough
to the right and it passes 1, and a probability of 1.2 has no meaning. A line cannot level
off. The function has to rise in the middle and flatten at both ends, which makes an S
shape.

## The curve on the slide

```
f(x) = 1 / (1 + e⁻ˣ)
```

Check it against the requirements.

- At `x = 0`: `e⁰ = 1`, so `f(0) = 1 / (1 + 1) = ½`.
- As `x` becomes large and positive: `e⁻ˣ` shrinks towards 0, so `f(x)` approaches
  `1 / (1 + 0) = 1`.
- As `x` becomes large and negative: `e⁻ˣ` becomes huge, so `f(x)` approaches `1 / huge = 0`.

The plot on the slide shows it running from 0 on the left, through ½ at the centre, to 1 on
the right. It is steepest in the middle and nearly flat by `x = ±6`.

A note on the name: the slide calls this the logit function. You will also see the same
S-shaped curve called the *logistic function* or the *sigmoid*, and it appears again when
the course reaches logistic regression.

## What the shape says

The curve is steep in the middle and flat at the ends, and that has a meaning. Between
closely matched players, a small rating edge shifts the odds noticeably. Between badly
mismatched players, extra rating points hardly matter, because the stronger player was
already going to win nearly every time. The probability never reaches exactly 0 or 1, so an
upset is always possible. Elo needs that, since an upset is what moves ratings most.

## Units

In `f(x)` a difference of 1 is already a big edge. Chess ratings are in the thousands, so
rating systems rescale the difference before putting it through the curve. That is the only
change in the worked example that follows.

> To turn any number into a probability, use a curve that passes through ½ at zero and
> flattens towards 0 and 1 at the ends.
