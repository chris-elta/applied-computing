Regression's first job is to fix the notation, which the rest of the week uses on every slide.

## The training set

Slide 13's data, house prices in Portland, Oregon:

| size in feet² (x) | price in $1000s (y) |
| --- | --- |
| 2104 | 460 |
| 1416 | 232 |
| 1534 | 315 |
| 852 | 178 |
| … | … |

The notation:

| symbol | meaning | here |
| --- | --- | --- |
| `m` | number of training examples | the number of rows |
| `x` | input variable, or feature | size |
| `y` | output, or target variable | price |
| `(x, y)` | one training example | one row |
| `(x⁽ⁱ⁾, y⁽ⁱ⁾)` | the i-th training example | `x⁽¹⁾ = 2104`, `y⁽¹⁾ = 460` |

The superscript `⁽ⁱ⁾` is an **index**: which row. It is not a power. `x⁽²⁾` is 1416, not 2104
squared. The brackets are there to keep the two apart.

## The pipeline

Slide 14 draws the process:

```
training set  →  learning algorithm  →  h
                                        ↓
                    size of house  →  h  →  estimated price
```

The learning algorithm takes the training set and outputs a function `h`, the **hypothesis**
(the name is historical). You then feed `h` a new house's size and it returns a predicted price.

## Representing h

For **linear regression with one variable**, also called **univariate linear regression**:

```
hθ(x) = θ₀ + θ₁x
```

It is the equation of a straight line: `θ₀` is the intercept and `θ₁` the slope. The `θ`s are
the **parameters**, the two numbers the learning algorithm has to choose.

The course notes give a small example. Training data:

| x | y |
| --- | --- |
| 0 | 4 |
| 1 | 7 |
| 2 | 7 |
| 3 | 8 |

Guess `θ₀ = 2` and `θ₁ = 2`, so `hθ(x) = 2 + 2x`. For `x = 1` it predicts 4, and the real
answer is 7: off by 3. Other choices of `θ₀` and `θ₁` give other lines, some closer to the data,
some further. Learning means finding the line that fits best, and the next concept defines
"best".

> A training set is m examples (x⁽ⁱ⁾, y⁽ⁱ⁾), with the superscript an index. The hypothesis
> hθ(x) = θ₀ + θ₁x is a line, and learning means choosing θ₀ and θ₁.
