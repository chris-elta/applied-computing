A house's price depends on more than its size. Slide 20 adds three more features:

| size (feet²) | bedrooms | floors | age (years) | price ($1000) |
| --- | --- | --- | --- | --- |
| 2104 | 5 | 1 | 45 | 460 |
| 1416 | 3 | 2 | 40 | 232 |
| 1534 | 3 | 2 | 30 | 315 |
| 852 | 2 | 1 | 36 | 178 |

## Notation

| symbol | meaning | example |
| --- | --- | --- |
| `n` | number of features | 4 |
| `m` | number of training examples | the number of rows |
| `x⁽ⁱ⁾` | all the features of example i, as a vector | `x⁽²⁾ = [1416, 3, 2, 40]` |
| `xⱼ⁽ⁱ⁾` | feature j of example i | `x⁽²⁾₃ = 2` (floors in row 2) |

The superscript picks the **row** (which house), the subscript the **column** (which feature).
The price is `y`, not a feature.

## The hypothesis

With one feature, `hθ(x) = θ₀ + θ₁x`. With n (slide 22):

```
hθ(x) = θ₀ + θ₁x₁ + θ₂x₂ + … + θₙxₙ
```

The course notes suggest reading it as a price: θ₀ is a base price, θ₁ the price per square foot,
θ₂ the price per bedroom, and so on. For example,

```
hθ(x) = 80 + 0.1x₁ + 0.01x₂ + 3x₃ − 2x₄
```

says each extra floor adds $3k and each year of age takes $2k off.

## The x₀ trick

The intercept θ₀ has no feature attached, which makes it a special case in every formula. Slide
22's fix: **define x₀ = 1** for every example. Then

```
hθ(x) = θ₀x₀ + θ₁x₁ + … + θₙxₙ
```

and every parameter has a feature. Now both `x` and `θ` are vectors of length n + 1:

```
     ⎡ x₀ ⎤          ⎡ θ₀ ⎤
x =  ⎢ x₁ ⎥     θ =  ⎢ θ₁ ⎥
     ⎢ ⋮  ⎥          ⎢ ⋮  ⎥
     ⎣ xₙ ⎦          ⎣ θₙ ⎦
```

## The vectorised form

The sum `θ₀x₀ + θ₁x₁ + … + θₙxₙ` is a row times a column, so (from the linear-algebra review):

```
hθ(x) = θᵀx
```

`θᵀ` is 1 × (n + 1), `x` is (n + 1) × 1, and the product is a single number. This is **multivariate
linear regression**.

The x₀ = 1 is the same column of 1s as in the matrix–vector concept, where it let one product
predict four house prices. Stacking every example's `x` as a row of a matrix `X`, the notes write
all `m` predictions as `Xθ`.

> With n features, the hypothesis is θ₀ + θ₁x₁ + … + θₙxₙ. Adding x₀ = 1 makes it θᵀx, one product,
> with superscripts for examples and subscripts for features.
