If generated content fills the web, a data scientist wants some way to tell it from the real
thing. The lecture's answer is **watermarking**: adding subliminal data to an object so that
it can be recognized as original.

## Two sketches

- **Low-order bit patterns.** Hide a pattern in the least significant bits of an image. The
  picture looks the same, but the pattern is there for a detector to find. The lecture's
  warning is that this **can be easily masked away.**
- **Text.** The slide says ChatGPT *may* watermark text by using a pseudo-random generator
  for decoding. The word "may" is the lecturer's: this is a possibility, not a guarantee you
  can rely on.

## What to take from it

Watermarking is a partial tool. It helps only when the generator cooperated in marking its
output, and only until someone removes the mark. For data collection the practical
consequence is the previous concept's second point: you cannot assume that recent web text or
images were made by people.

> A missing watermark is not evidence that content is real, and a present one can be
> removed. Provenance of your data is something to establish, not assume.
