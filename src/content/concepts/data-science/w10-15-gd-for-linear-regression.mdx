Gradient descent works on any function with slopes. This concept plugs in linear regression's
`hθ` and `J` to get rules you can actually compute.

## The two ingredients

Slide 7 puts them side by side:

```
hθ(x) = θ₀ + θ₁x
J(θ₀, θ₁) = (1 / 2m) Σᵢ₌₁ᵐ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾)²
```

Work out the two partial derivatives (slide 8; the derivation is beyond the course):

```
∂J/∂θ₀ = (1/m) Σᵢ₌₁ᵐ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾)
∂J/∂θ₁ = (1/m) Σᵢ₌₁ᵐ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾) · x⁽ⁱ⁾
```

The ½ in `J` has cancelled the 2 from differentiating the square, as promised in the
cost-function concept.

## The update rules

Slide 9:

```
repeat until convergence {
    θ₀ := θ₀ − α (1/m) Σ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾)
    θ₁ := θ₁ − α (1/m) Σ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾) · x⁽ⁱ⁾
}                                   (update θ₀ and θ₁ simultaneously)
```

In words: compute every training example's error. θ₀ moves by the **average error**. θ₁ moves by
the **average error weighted by x**. The only difference is that trailing `· x⁽ⁱ⁾`, which comes
from the derivative of `θ₁x`.

The intuition is good. If the line predicts too high on average, the errors are positive and θ₀
comes down. If it is too high mostly on the large houses, the x-weighted errors are positive and
the slope comes down.

## A worked step

Two training examples, (1, 2) and (2, 4). Start at θ₀ = θ₁ = 0, with α = 0.1.

| x | y | hθ(x) | error | error × x |
| --- | --- | --- | --- | --- |
| 1 | 2 | 0 | −2 | −2 |
| 2 | 4 | 0 | −4 | −8 |
| | | **mean** | **−3** | **−5** |

```
θ₀ := 0 − 0.1 × (−3) = 0.3
θ₁ := 0 − 0.1 × (−5) = 0.5
```

Both computed from the old values, then assigned together. The line is now `0.3 + 0.5x`,
closer to the data's `y = 2x`.

## Watching it converge

Slides 10–18 run the algorithm on the house-price data. Each pair shows the current line on the
left and its position on the contour plot on the right. The red point starts far out, and each
step moves it inward; the line swings round from a steep downward slope to one running through
the data. By slide 18 the point is at the centre of the ellipses.

## No false minima

Part 1 showed gradient descent on a bumpy surface landing in different valleys from different
starts. That cannot happen here. The squared-error cost for linear regression is **convex**: a
single bowl with one bottom. Its only local minimum *is* the global minimum, so gradient descent
with a suitable α always gets there, from any start.

Each step's sums run over all `m` training examples, so every iteration costs one full pass
over the data. That cost is what the gradient-descent-against-normal-equation comparison
later this week weighs.

> For linear regression, gradient descent moves θ₀ by the average error and θ₁ by the average
> error times x, scaled by α. Because the cost is a convex bowl, it always reaches the global
> minimum.
